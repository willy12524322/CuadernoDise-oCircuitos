# 📖 Glosario · Diseño de Circuitos (Unidad 1)

[⬅️ Volver al índice](../README.md)

Los términos están en orden alfabético, con la semana donde aparecen entre paréntesis.

| Término | Significado |
|---|---|
| **Absorción** | Teorema que elimina términos redundantes: `X + XY = X` (S2) |
| **Acarreo (carry)** | El dígito que «me llevo» al sumar una columna (S4) |
| **ALU** | Unidad aritmético-lógica: la parte del procesador que suma, resta, compara y hace operaciones lógicas (S4) |
| **APE** | Actividad de práctica experimental que se realiza en el laboratorio con Logisim-evolution |
| **ASCII** | Tabla acordada que asigna un número de 7 bits a cada carácter (S1) |
| **BCD** | Código decimal en binario: cada dígito decimal se guarda en 4 bits (S1) |
| **Bit / Byte** | Un dígito binario / 8 bits (S1) |
| **Complemento a dos** | Acuerdo para representar negativos: invertir los bits y sumar 1 (S1) |
| **Consenso** | Teorema: `XY + X'Z + YZ = XY + X'Z` (S2) |
| **De Morgan** | Leyes que convierten un producto negado en suma de negados y viceversa (S2) |
| **Dualidad** | Intercambiar `+` ↔ `·` y `0` ↔ `1` conserva la validez de una identidad (S2) |
| **Forma canónica** | Expresión única de una función, hecha solo de minitérminos (SOP) o de maxitérminos (POS) (S2) |
| **Gray (código)** | Código donde entre vecinos cambia un solo bit; define el orden del mapa de Karnaugh (S1, S3) |
| **Idempotencia** | `X + X = X` y `X·X = X` (S2) |
| **Implicante** | Cualquier grupo válido de 1 (o X) en un mapa (S3) |
| **Implicante primo** | Implicante que ya no se puede agrandar (S3) |
| **Implicante primo esencial** | El único primo que cubre algún 1; obligatorio en la solución (S3) |
| **Indiferente (X)** | Combinación que nunca ocurre; se usa como 1 o como 0 según convenga (S3) |
| **Literal** | Una variable, complementada o no, dentro de una expresión (S3) |
| **Margen de ruido** | Colchón de voltaje que protege a un 0 o a un 1 de las interferencias (S1) |
| **Maxitérmino (Mᵢ)** | Suma que vale 0 solo en la fila i (S2) |
| **Minitérmino (mᵢ)** | Producto que vale 1 solo en la fila i (S2) |
| **NAND / NOR** | Compuertas «universales»: con una sola de ellas se construye cualquier circuito (S1, S3) |
| **Overflow (desbordamiento)** | El resultado no cabe en los bits disponibles (S1, S4) |
| **POS** | Producto de sumas: se leen las filas donde F = 0 (S2) |
| **Ripple (carry)** | Sumador en cadena donde el acarreo avanza etapa por etapa, como una ola (S4) |
| **Semisumador** | Suma 2 bits y no admite acarreo de entrada (S4) |
| **SOP** | Suma de productos: se leen las filas donde F = 1 (S2) |
| **Sumador completo** | Suma 3 bits: A, B y el acarreo que llega (S4) |
| **Tabla de verdad** | Lista de todas las combinaciones de entrada con su salida |
| **Zona indefinida** | Rango de voltaje (0,8 a 2,0 V en 74LS) donde el chip no garantiza leer 0 o 1 (S1) |
| **74LS / 74HC** | Familias de circuitos integrados: LS es TTL, HC es CMOS (S1) |
| **7400 · 7402 · 7404 · 7408 · 7410 · 7411 · 7432** | NAND · NOR · NOT · AND · NAND de 3 · AND de 3 · OR |
